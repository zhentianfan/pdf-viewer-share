# PDF 在线查看工具

个人非商业的 PDF 查看工具测试项目。这是一个供审核的离线静态包，尚未部署。

## 加密内容

公开包只包含通用查看器和 `data/` 下的加密文件，不包含明文 PDF、解密密钥、文件映射或文件列表。每份文档使用独立的 AES-256-GCM 密钥和 12 字节随机 IV；加密文件格式为 IV（12 字节）加密文及认证标签（16 字节）。

专用链接把密钥放在 URL fragment（`#` 后的部分）。浏览器读取后立即从地址栏移除 fragment，在本地解密并使用同源 blob URL 交给 PDF.js 显示。fragment 不随 HTTP 请求发送。网站不使用第三方脚本、分析服务、浏览器持久化存储或密钥日志。持有完整专用链接的人可查看对应文档。

## 静态部署

将 ZIP 内容直接展开到站点根目录。所有资源均使用相对路径，适配 GitHub Pages 仓库路径。使用 HTTPS；Web Crypto 需要安全上下文。`.nojekyll` 已包含，不配置自定义域名。

部署前请审核本包。明文原件与密钥清单单独保留在本地，不能上传至公开仓库。主页无文件目录，全部 HTML 声明不收录，`robots.txt` 禁止抓取。

PDF.js 使用原项目许可证，见 `pdfjs/LICENSE`。
